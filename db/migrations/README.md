# db/migrations

Prisma migration history (Blueprint §7.6). The first migration
establishes the seven bounded-context schemas (Blueprint §7.2), Row-Level
Security policies (§7.3), the append-only Financial Transaction event log
(§7.4), and the temporal GROUP_MEMBERSHIP model (§7.5).

**Status (Sprint 1.3): DRAFT, not yet applied to a real database.**
`20260801000000_init_bounded_context_schemas/migration.sql` was
hand-written to match `db/schema.prisma`, not generated by `prisma
migrate dev` against a live PostgreSQL instance - no database or package
registry access was available in the environment that authored it. See
`db/DESIGN_NOTES.md` for exactly which parts of this migration are
evidenced by already-committed code (`libs/rbac`, every domain library's
README) versus inferred, and the open questions that need the real
Blueprint §7.2-7.5 text to close.

Before this migration is trustworthy: run `pnpm db:validate`, apply it to
a real local PostgreSQL instance, and confirm `prisma migrate diff`
against the applied database comes back empty.
